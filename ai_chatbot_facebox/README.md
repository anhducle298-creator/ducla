# AI Chat Bot FaceBox

Project rieng cho chatbot AI FaceBox. Muc tieu la tao bot co the hoi dap, ghi nho hoi thoai ngan han, va sau nay ket noi Telegram, API noi bo hoac dashboard.

## Cau truc

```text
ai_chatbot_facebox/
  app.py
  config.py
  storage/
  services/
  bot/
  docs/
```

## Chay thu

```bash
cd D:\my_project\ai_chatbot_facebox
python app.py
```

Mac dinh app chay o che do console demo. Khi cau hinh Telegram token thi co the bat bot Telegram sau.

## Huong phat trien

1. Ket noi Telegram bot.
2. Them AI provider de tra loi tu nhien.
3. Them database luu lich su hoi thoai.
4. Them tri thuc rieng cho FaceBox.
5. Them phan quyen nguoi dung.
