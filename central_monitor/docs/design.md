# Thiet Ke Central Monitor

## Inventory

Quan ly danh sach thiet bi va service:

- device_type: AIBOX, CAMERA, SERVER, SERVICE
- site
- name
- ip
- status
- owner
- note

## Event

Event can ghi nhan:

- DOWN
- RECOVERY
- RESOURCE_ALERT
- RESOURCE_RECOVERY
- SERVICE_DOWN
- SERVICE_RECOVERY

## Nguon Du Lieu

- Email alert
- Prometheus/Grafana
- SSH command
- API noi bo
- Ping/healthcheck
